CSS - Cascading Style Sheet

Inline Css

The paragraph style is given using both Inline & External CSS attribute.Inline CSS involves adding style properties directly into individual HTML elements using the style attribute.

Internal Css

The paragraph style is using Internal CSS. The css is also called as Embedded Css which is a method used to style a single, specific HTML page by placing code directly inside a style tag within the head section of the document.

External Css

External CSS is a method of styling a website where all Cascading Style Sheet (CSS) rules are written in a completely separate file with a .css extension. This external file is then connected to one or more HTML documents using the link tag placed inside the head section of the HTML.
